# Butterfly Image Classification

## Install dependencies

Install the required Python packages from a terminal:

```bash
py -m pip install pandas pillow scikit-learn
```

## Dataset

This project requires the `train/` and `test/` folders from the
[Butterfly Image Classification dataset on Kaggle](https://www.kaggle.com/datasets/phucthaiv02/butterfly-image-classification/data).

Download the dataset from Kaggle and extract it. Place the `train/` and `test/`
folders either in the root of this repository or together inside a `Butterfly/`
subfolder. For example:

```text
project-root/
├── train/
├── test/
└── README.md
```
